# Raciocínio Algorítmico e RMC (1º semestre)

Exercícios em Python do 1º semestre de Engenharia de Software (PUCPR).

## `RMC/`
Aulas da disciplina RMC.
- `aulas/`: exercícios feitos em aula, como conversões, strings, listas, conjuntos, funções, NumPy, gráficos com Matplotlib, Flask, um jogo de adivinhação (`game.py`) e um jogo da velha (`geme_velha.py`)
- `aulas/exTDE1.ipynb`: exercícios do TDE1 em notebook Jupyter
- `main.py`: script inicial do projeto

## `Raciocinio_Algoritmico/`
Aulas da disciplina Raciocínio Algorítmico.
- `api.py`: primeira API em Flask, com as rotas `/` e `/soma`
- `aula3.py`: API Flask que calcula soma, subtração e multiplicação (`/calcular/<a>/<b>`)
- `Aula_HTML-CSS/`: páginas da aula de HTML e CSS

O trabalho de Machine Learning está no repositório [Notavel](https://github.com/franpietrobelli-creator/Notavel), e os TDEs de RMC estão em [TDEs_RMC](https://github.com/franpietrobelli-creator/TDEs_RMC).

## Como rodar

```bash
pip install numpy matplotlib flask
python RMC/aulas/aula1.py
```
